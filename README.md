# 🍚 纯过日子 · JustLiving

**开源共建的普通人生活指南。日子照过，但不烧心。**

不卷最优解，不花冤枉钱，不操没必要的心。

这个世界有太多人教你如何成功、如何逆袭、如何成为更好的自己。
但我们只想研究一件事：**一个普通人，怎样把日子过得舒服一点？**

不用什么都买最贵的，不用什么事情都做到极致，不用为了省几块钱折腾半天，也不用因为别人的生活而焦虑。
这里没有人生导师，只有一群认真过日子的普通人。

**人人分享一点真实经验，大家少走一点冤枉路。** 欢迎分享你的经验，也欢迎纠正我们的错误。

## 每个人都能贡献

生活里的好经验，值得被更多人看见。

- 分享经验：通过投稿入口，写下你亲自尝试过的生活方法、踩过的坑，或者省心的小技巧。
- 补充完善：如果你有更好的做法，欢迎补充内容、提出不同意见，让经验更加实用。
- 帮助纠错：发现内容不准确或已经过时，可以告诉我们具体情况和参考依据。
- 一起维护：欢迎愿意长期参与的朋友，一起整理内容、核对信息、友善交流。

不需要专业背景，也不必写得多么完整。一段真实经历、一条实用建议，甚至一次失败的尝试，都可能帮到别人。

## 我们怎样对待经验

真实、实用、有边界，是我们整理生活经验的基本原则。

我们希望每一条经验都能回答几个问题：适合谁、什么情况下有用、具体怎么做，以及有哪些需要注意的地方。

生活没有统一的标准答案。不同城市、不同预算、不同生活阶段，适合的方法也可能完全不同。

我们欢迎不同的声音，也重视每一次认真纠错。经验会随着大家的分享和讨论不断补充、修正，让这份指南越来越可靠。

不追求每条建议都适合所有人，只希望每个人都能从中找到一点有用的东西。
